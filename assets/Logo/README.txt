LOGO FOLDER
===========

puthi-mark.svg   The logo. The website reads this one file and draws it in the
                 header, in the big animated flame, and in the download panel.
                 To change the logo everywhere: replace this file (keep the same
                 name), commit, wait a minute, refresh the site.

                 Rules for a new file: flame pixels are <rect> shapes with a fill
                 colour; the book is one <path> with a stroke. An Illustrator
                 export works as it is.

puthi-icon.svg   Square version with the warm glow behind the mark. Used as the
                 browser-tab icon.

Pictures (these are images, so they do NOT update by themselves; export new ones
from your design file when the logo changes):
favicon.png, apple-touch-icon.png, logo-512.png, logo-large.png,
cover.png, og-cover.png (the picture shown when the link is shared).
